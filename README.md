# 🍔 BiteCentral

> El centro del sabor artesanal.

**BiteCentral** es una plataforma web desarrollada para conectar a los fanáticos de las hamburguesas gourmet con los mejores locales artesanales e independientes. Funciona como un directorio interactivo donde los usuarios pueden explorar opciones, ver puntuaciones y realizar pedidos directamente.

---

## 🎨 Características y Diseño

* **Estética Dark Mode:** Interfaz oscura con acentos dorados (`#D4AF37`) pensada para destacar el producto y transmitir una imagen moderna.
* **Layout Responsivo y Flexbox:** Estructura adaptable construida con CSS Flexbox y reglas de box-sizing (`border-box`) para asegurar una correcta visualización en diferentes pantallas.
* **Tarjetas Reutilizables (`.tarjeta`):** Componentes basados en clases CSS independientes para escalar el número de locales fácilmente.
* **Llamados a la Acción (CTAs):** Botones claros como `¡PEDIR YA!` y `EXPLORAR LOCALES` diseñados para mejorar la conversión.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Estilos personalizados, arquitectura basada en clases y layout flexible.

---

## 💼 Modelo de Negocio (B2B)

El proyecto incluye una lógica de monetización pensada para presentaciones y pitches profesionales:

1. **Suscripción por Membresía:** Los locales gastronómicos pagan un abono mensual para figurar en el directorio y obtener visibilidad.
2. **Posicionamiento Premium:** Espacios destacados en la pantalla principal para aumentar las ventas de los locales adheridos.
3. **Estrategia de Tráfico Orgánico:** Promoción del portal mediante contenido viral en TikTok e Instagram (rankings, reseñas) para dirigir usuarios calificados al sitio.
